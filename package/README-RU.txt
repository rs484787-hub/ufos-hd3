UFOs для Windows 11
===================

1. Распакуйте архив в любую папку, например D:\Games\UFOs
2. Скопируйте в папку Game всё содержимое папки игры UFOS
   (у вас это D:\TEMP\UFOs\UFOS): UFOS.EXE, UFOS.INI, все *.DAT, HOFFMAN.AVI, PAUSE.MID.
3. Запустите UFOs.exe - игра откроется сразу, во весь экран.

Alt+Enter  - переключить окно / полный экран
Ctrl+F5    - меню (сохранение, загрузка, настройки, выход)

Сохранения лежат в папке Saves, настройки - в файле UFOs.ini.
Внутри работает движок ScummVM (GPL v3, лицензии - в файлах COPYING*.txt).
